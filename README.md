# Wexford Home Search

A one-page site listing one-floor homes with attached garages near Wexford, PA.
Published with GitHub Pages at https://bobz4ai.github.io/wexford-home-search/

To rebuild after editing the data files in `src/`:

    cd src && python3 build.py "Month D, YYYY" "next update text" && cp out/index.html ../index.html
